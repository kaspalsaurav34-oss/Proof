# PROOF Prototype

This project is a zero-budget, browser-based prototype for the PROOF platform.

## What is included

- Premium dark startup-style landing page
- Mission explorer with category filters and search
- Submission workflow with status states and validation
- Student dashboard with joined missions and sample submissions
- Portfolio view with public/private sharing controls
- Responsive behavior for phone, tablet, and desktop screens
- Demo-only data clearly labeled in the UI

## Run locally

Because this is a static front-end prototype, you can open `index.html` directly in a browser.

If you want a local server instead, run one of these commands from the project root:

- Python: `python -m http.server 8000`
- Node: `npx serve .`

Then open: `http://localhost:8000`

## Notes

- This is a prototype and does not include a real backend or authentication.
- Verification is intentionally not automated and is represented as a demo workflow only.
- The app uses demo data and clearly marks it as such.

## Files

- `index.html` — page structure
- `styles.css` — dark premium design system and responsive layout
- `script.js` — interactive mission filtering, dashboard behavior, and form handling
